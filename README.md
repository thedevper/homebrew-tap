# thedevper/homebrew-tap

```sh
brew install thedevper/tap/rodu
```

| Formula | |
|---|---|
| [rodu](https://github.com/thedevper/rodu) | Local-first, AI-first kanban for small teams |

Formulae are generated by each project's release build; update them from the release's `rodu.rb`.
`formula_renames.json` moves installs of `shoal` (Rodu's name before 0.2.0) to `rodu` on `brew upgrade`.
